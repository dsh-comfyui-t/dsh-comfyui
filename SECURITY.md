# Security Policy

## Reporting a vulnerability

Do not open a public issue. Report privately through GitHub Security Advisories:

    https://github.com/dsh-comfyui-t/dsh-comfyui/security/advisories/new

Include the affected version or commit, a reproduction, and the impact you believe it has.
Expect an initial response within 7 days. This project is maintained by one person;
fixes for confirmed issues are prioritised over feature work.
