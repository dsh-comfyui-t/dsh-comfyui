## 真实 3D 静态涟漪与手动编辑（2026-10-29，Proto）

新建场景背景默认 #FFFFFF；读取已有场景时保留其背景选择。镜面仍使用本地 8K 蓝天白云。

涟漪由实际带正/负高度的网格与法线构成，不再通过平面圆圈纹理表示。几何起伏参与深度、反射扭曲、定向光高光及阴影投射。外缘回到平面，重叠来源合成连续表面以避免相交闪烁；不运行时间动画。单组采用 192 个周向段、每圈 16 个径向采样；重叠表面使用有上限的网格重建，静止时复用。

自动接触来自真实姿势三角面与地面的交线；相邻/重叠接触碎片合并，同一连续接触区只产生一组。`groundGrid.autoRipples` 保存区域标识、关联物体、中心、接触尺寸和随机圈数。新区域随机 4–6 圈，随后移动/调整大小、截图、保存重开及撤回重做均保留；离开地面后再次进入才创建新的随机圈数。

`rippleSize` 为全局涟漪大小，默认 3，范围 0.25–12。结合接触尺寸自动缩放，默认外半径至少为旧版纹理范围的 3 倍。`manualRipples` 保存手动组的 ID、x/z、大小与 4–6 圈；只在镜面模式添加/选择，独立的移动手柄锁定世界 X/Z 平面，可选择、调大小、删除。每类最多 16 组。手动与自动来源可重叠，但共享物理表面；选择按手动源的位置判断。

自动随机结果在当前历史快照及草稿中持久化，不为圈数初始化额外创建撤回步骤。关闭与截图继续等待原保存流程；截图与镜面反射都排除手动移动手柄。原预设、相册、图生图截图和隐藏模型规则不变。

## 半径、间距与固定圈数（2026-10-29，Proto）

## 参数独立与静态水波曲面重构（2026-10-29，Proto）

密集度控件步长 0.5、可调范围 0.5–32，数值越小越密。圆环中心线间距统一为 RIPPLE_SPACING * density（RIPPLE_SPACING=0.09 米），不再把波宽加进间距，也不再取密集度的倒数。第一圈中心线半径由「涟漪半径」确定，后续中心线为 radius + i*spacing，固定 4–6 圈。宽度只改变各中心线两侧的波形，中心线半径和圈距不变；渲染覆盖边界为最后一圈加波形支撑宽度，不能反推或冒充半径。

反射使用平滑的法线偏转，减少过度扭曲；高光改为水面介质的 Schlick Fresnel / GGX 形式并加入法线方差抗锯齿，取消旧的蓝白色硬高光叠加。明暗随观察角度平滑变化，并在平坦区域与原镜面连续。保留 8K 本地天空、物理像素反射/MSAA、模型阴影、静态截图与保存握手。

此前拖拽框边缘修改宽高/frameScale 后，适应窗口的 verticalScale 会参与整个视口投影；尤其横向锁比例时，高度变化导致整幅场景拉近或拉远。现将裁剪范围与视口投影解耦：按拖拽前后框布局计算 frameProjectionScale，使视口的有效 verticalScale 保持不变；相机位置、方向、zoom、fov 参数均不变。

同一补偿用于拍照/第一人称的横纵边缘、比例锁定、旋转后边缘，以及尺寸预设/手输宽高。R 倾斜取景框时也补偿自适应布局带来的变化。预览与导出分别按视口布局及该补偿计算投影，倾斜框与最终图片仍精确对应；正交镜头使用相同规则。fov 控件本身仍用于主动调整透视，未被改写。

frame_resize.js 集中计算拖拽与投影补偿，纳入运行资源检查；frameProjectionScale 随每个镜头保存，旧场景缺少时默认 1，服务端仅接受有限正值。保留第一人称固定眼位、角度显示、截图、撤回与 AI 助手隐藏状态。
